# Goodgrowth

A free weekly content and community planner for organic social media growth. Choose a platform, describe your topic and audience, and get seven practical post prompts and community actions.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Run the production build with `npm run build`, and lint with `npm run lint`.

## What it does

- Creates a platform-specific plan for Instagram, TikTok, YouTube, LinkedIn, or Facebook.
- Tailors prompts to a creator's topic, audience, goal, and posting pace.
- Tracks completed days and saves the plan in the current browser's local storage.
- Lets users copy the plan to their clipboard.

## Privacy and limitations

Goodgrowth does not require an account, connect to social networks, or send form data to a server. It does not automate likes, follows, comments, or messages, and it cannot guarantee engagement or follower growth. The generated plan is a set of editable suggestions; creators should follow each platform's rules and use their own judgment.

The interface loads its typefaces and hero photograph from Google Fonts and Unsplash. A network connection is needed to load those remote assets; the planner itself runs in the browser.
